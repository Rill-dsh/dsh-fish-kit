# 06 让它会干活

`kit/` 里的脚本都是**命令行**的，因为它们要被 AI 自己调用，也要能被
定时任务调用。没有界面，只有输入输出——这恰好是最稳的接口。

---

## 6.1 全部脚本

| 脚本 | 干什么 | 典型调用 |
| --- | --- | --- |
| `doctor.py` | 自检：哪条没通 | `python doctor.py` |
| `qq-send.py` | 私聊发文字（按空行分段） | `python qq-send.py 123456 "在呢"` |
| `qq-send-group.py` | 群里发文字 | `python qq-send-group.py 87654 "在呢"` |
| `qq-send-img.py` | 私聊发图 / 图文 | `python qq-send-img.py 123456 "" a.gif` |
| `qq-send-group-img.py` | 群里发图 | `python qq-send-group-img.py 87654 "" a.gif` |
| `voice.py` | 发语音条（克隆音色） | `python voice.py --text "话" --private 123456` |
| `bili-dm-check.py` | 查 B站私信 | `python bili-dm-check.py` |
| `dy-check-notice.py` | 查抖音 @ / 评论 | `python dy-check-notice.py` |

全部读同一份 `kit/config.json`（或环境变量 `FISH_CONFIG` 指的文件）。
**没有一处硬编码路径或 QQ 号**，换机器只要换配置。

## 6.2 三个约定

这三个约定是这套脚本能当「手」用的原因：

### (1) 成功失败都输出一行 JSON

```json
{"ok": true, "返回": {...}, "条数": 2}
{"ok": false, "错": "正文里有句号，扫掉再发", "位置": [12]}
```

AI 读这一行就知道成没成，不用解析自然语言。

### (2) 退出码跟结果一致

`0` = 成功，非 0 = 失败。定时任务和看门狗靠这个判断。

### (3) 正文里的空行 = 一条消息

```bash
python qq-send.py 123456 "在呢

刚看到个东西

可能你会喜欢"
```

发出去是三条独立消息，间隔 0.45 秒。**这是刻意的**：
一大坨堆在一条里，手机上看着像公告。

## 6.3 分段：为什么不是换行

因为「一句一行」是 AI 最容易写出来的格式。如果把换行也当分段，
它每说一句就发一条，五句话炸成五条消息，比一大坨更烦。

所以规矩是：**空行才分段，单个换行不分。**
让 AI 自己决定哪些话该分开说。

## 6.4 句号拦截

`qq-send.py` 发之前会扫一遍句号，有就拒绝发：

```json
{"ok": false, "错": "正文里有句号，扫掉再发", "位置": [12]}
```

这不是洁癖。中文默认就是句号收尾，越长的回复越容易带。
靠「记住别写句号」一定会漏，靠机械检查才是真拦得住。

## 6.5 配定时任务

三种做法，按简单到复杂：

### (1) 系统计划任务

Windows 任务计划程序 / Linux cron，到点跑一个命令行。

```bash
# 每 30 分钟查一次私信（Linux）
*/30 * * * * cd /path/to/kit && /usr/bin/python3 bili-dm-check.py
```

### (2) 让 DSH 自己排

DSH 里有 `schedule_create` 那类工具，可以让 AI 自己给自己排提醒。
好处：提醒内容是**自然语言**，它到点得自己判断「现在要不要做」；
坏处：要花模型的钱。

### (3) 混合

硬性的检查（有没有人找你）用系统任务；需要判断的事（要不要发动态）
用 DSH 的提醒。

## 6.6 一个真实的「一天」

```
08:40  speak-up 掷中 → 发一条「起了没」
12:30  定时：问自己要不要发空间动态 → 想发就不发
13:30  系统任务：bili-dm-check / dy-check-notice → 都没有，静默
18:00  speak-up 掷中 → 刷了一圈B站，挑了一条发过去
21:30  定时：检查私信 → 有一条，回它，并在 QQ 说一声
23:50  speak-up 掷中 → 看时间，不发
```

一天里真正说出话的只有三四次。**大部分时间它在看，不在说。**

## 6.7 写自己的脚本

要加新能力，照这三个约定写就行：

```python
import fishlib

def main():
    ok, data = fishlib.onebot("send_private_msg", {
        "user_id": 123456,
        "message": "干完了",
    })
    print(json.dumps({"ok": ok, "返回": data}, ensure_ascii=False))
    return 0 if ok else 1
```

`fishlib` 已经把配置、发消息、拆段、记流水、句号检查都封好了。
