# 02b 接上 B 站和抖音

目标：**它知道你在 B 站和抖音上有没有被人找到，需要的时候也能替你在那儿说话。**

和 QQ 有个根本区别，先说清楚：

- QQ 是**双向实时**的 —— 你说话它听得见，它说话你手机上立刻收到
- B 站和抖音是**只读 + 偶尔开口** —— 它按定时器去探一眼（有没有新的 @、评论、私信），
  探到了才叫醒它。主动发东西是另一回事，要单独开闸

```
B站 API ─┐
          ├─→ 定时脚本（探一眼） ─→ 有新消息 ─→ 叫醒它 ─→ 告诉你 / 替你回
抖音 API ─┘
```

---

## 2b.1 先选一档，别全开

| 档 | 它做 | 代价 |
| --- | --- | --- |
| 只看不说 | 探到新消息，只告诉你 | 最小，**从这里起步** |
| 能回私信 | B 站私信它替你回 | 发出去收不回，得先看两遍 |
| 能发评论/动态 | 在别人内容下面说话 | 风控 + 社交后果，默认别开 |

一开始只开第一档。第二档等它回得稳了再说。第三档……先别。

## 2b.2 B 站：凭证从哪来

B 站所有接口都要登录态，要四个值：

- `SESSDATA` —— 登录凭证主体
- `bili_jct` —— CSRF 令牌，发东西时要用
- `buvid3` —— 设备标识
- `DedeUserID` —— 你自己的 UID

登录 B 站 → F12 → Application → Cookies → 抄下这四个，存成一个 json：

```json
{
  "sessdata": "…",
  "bili_jct": "…",
  "buvid3": "…",
  "dedeuserid": "…"
}
```

把它填进 `kit/config.json` 的 `bili.credential`。**这个文件别提交进 git。**

> 凭证会过期，一个月到半年不等。过期后接口会返回 `code: -101` 或 `-400`，
> 那时候重抄一遍就行。

## 2b.3 B 站：查私信

```bash
cd kit
python bili-dm-check.py
```

- 有新的：一行一条，`NEW bili-dm 2026-11-20 22:31 | 谁：说什么`
- 没有：`no new`
- 退出码 0 = 查成功（不管有没有新消息）；1 = 没查成

它先直连 `api.vc.bilibili.com`，**TLS 握手被重置时自动换 curl 再试一遍**。
不是洁癖：这个域名在某些线路上握手会被硬重置，urllib 直接连不上，curl 能过。
两个都试，谁通用谁。

## 2b.4 B 站：回私信

发私信要带上 `bili_jct`。裸调 API 容易踩 412（请求缺 UA 被风控拦），
所以更省事的办法是装一个带 `bili_send_message` 的插件，
在 DSH 会话里让它自己回 —— 传参、签名、UA 插件都替你处理了。

**规矩**：回之前先看对方是谁、说了什么。私信是别人能看见的窗口，
别在那儿背台词，也别把对主人的话原样发出去。

## 2b.5 抖音：cookie 从哪来

抖音用的是 web 端 cookie，形状是：

```json
{
  "cookies": [
    {"name": "ttwid", "value": "…", "domain": ".douyin.com"},
    {"name": "sessionid", "value": "…", "domain": ".douyin.com"}
  ]
}
```

拿法：浏览器登录抖音 → 用 EditThisCookie 之类的扩展一键导出（选 JSON 格式）→ 存盘。
填进 `kit/config.json` 的 `douyin.cookies`。

## 2b.6 抖音：查通知

```bash
python dy-check-notice.py
```

- 有新的：一行一条，带类型（@ / 评论 / 私信）和时间
- 没有：`no new`
- 结果同时落到 `daily/dy-notices.json`，别的脚本能接着用

**风控注意**：查得太勤、或者 cookie 快过期的时候，接口会返回**空列表而不是报错**。
空列表就当「这次没事」，**别重试、别换 IP 硬撞** —— 越撞越像机器人，
真被风控了要你手动过验证。

## 2b.7 抖音：发评论（放最后做）

难点不在接口，在页面。图文页（`/note/`）的评论输入框，插件经常找不到，
得先点文本以 `评论(` 开头的那个 tab，再按坐标点输入区，等 Draft.js 的
`div.notranslate.public-DraftEditor-content` 出来，才能往里打字。

**别指望它全自动。** 要么人工点一下，要么接受它只能发视频页的评论。

## 2b.8 接上定时任务

三个平台各一个检查脚本，串进同一个定时器：

```powershell
# 每 30 分钟一次；谁有新消息就吱一声
python bili-dm-check.py
python dy-check-notice.py
```

规矩，这几条是血换来的：

1. **全都没有 → 一个字都不要说。** 每天定时汇报「今天没有新消息」是最快的取关理由。
2. **别为刷而刷。** 探到才叫醒它，没探到就让定时器空转，别硬凑活动。
3. **先告诉主人。** 探到的事先跟你说，不是直接冲去评论区接话。

## 2b.9 排障

| 现象 | 多半是 |
| --- | --- |
| 返回 `code: -101` | B 站凭证过期，重抄四个值 |
| 返回 `code: -412` | 缺 UA 或被风控，加上 UA、等半小时 |
| 抖音返回空列表但你知道确实有消息 | cookie 快过期了，或者这次真的是空的 |
| 报 `找不到 config.json` | 不在 `kit/` 目录下跑的，或者没复制 `config.example.json` |
| 私信发不出去 | `bili_jct` 不对或过期了 |
| 查得通但从来没动静 | `watch_uid` 没填，脚本不知道该盯谁 |
