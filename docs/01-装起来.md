# 01 装起来

先把「能对话」这一步走通，别一上来就接 QQ。**分两段走**：
模型先能答话，再谈让它找到你。

---

## 1.1 装 DeepSeek Harness

去 DeepSeek 官网装 DSH（桌面版）。装完打开，随便说一句话，它能答，就算过了。

记下两件事：

- DSH 的工作目录在哪（后面 `AGENTS.md` 要放这里）
- 它用的模型是什么（人格文件里要写清楚底子）

## 1.2 建一个「窝」

别把东西全堆在 C 盘桌面。建一个文件夹，比如：

```
D:\fish\
├── workspace\      工作目录（AGENTS.md、kit\ 放这儿）
├── daily\          每日流水
├── memory\         记忆库
├── stickers\       表情包
└── voice\          声音参考
```

**为什么先建窝**：路径写死一次，后面所有脚本、定时任务、记忆库都指这儿。
换来换去，那些写死的路径迟早会指错。

## 1.3 装插件

插件是 npm 包，装在 DSH 的 profile 里。三个是刚需。

**图形界面（最不容易错）**：设置 → 插件 → 安装，一行一个填进去：

```
github:Yuuyuko-uu/dsh-qq-bridge
github:Yuuyuko-uu/dsh-fish-memory
github:Yuuyuko-uu/dsh-speak-up
```

**命令行**（`--profile` 照你平时用的写，桌面端一般 `desktop`，网页端 `web`）：

```bash
# QQ 通道：它说话发 QQ，你在 QQ 说话转进来
dsh plugin --profile desktop add github:Yuuyuko-uu/dsh-qq-bridge

# 记忆：会话被压缩之后还记得住
dsh plugin --profile desktop add github:Yuuyuko-uu/dsh-fish-memory

# 主动开口：没人在的时候它也会自己起个话头
dsh plugin --profile desktop add github:Yuuyuko-uu/dsh-speak-up
```

**装完重启一次 DSH**，然后进 设置 → 插件，确认三个都在。

> 起不来又报 `Unexpected token` / `is not valid JSON` / `readProfileManifest`？
> 那不是插件的问题，是 profile 的 `package.json` 被存成了 UTF-8 带 BOM。
> 文件内容都是对的，只是开头多了三个看不见的字节。见 `99-踩过的坑.md` 第 13 条。

可选的还有：

| 插件 | 干什么 | 什么时候要 |
| --- | --- | --- |
| `dsh-bili-subagent` | 派子代理去刷 B 站，回来跟你讲 | 你想让它替你刷内容 |
| `dsh-douyin` | 抖音：看、搜、评论 | 你要它在抖音上活动 |
| `dsh-feiyu-mood` | 心情 / 状态面板 | 你想看见它「今天什么心情」 |

## 1.4 把人格和规矩放进去

```bash
# 把模板复制成你自己的版本，别直接改模板
cp persona/人格卡.template.md   <窝>\workspace\人格卡.md
cp persona/学说话.template.md   <窝>\workspace\学说话.md
cp persona/AGENTS.template.md   <窝>\workspace\AGENTS.md
```

然后**现在就去填第一版**，每份只用十分钟：

- `AGENTS.md` 只填第 1 节（查记录）和第 3 节（发消息三条硬规矩）
- `人格卡.md` 只填「我是谁」和「我怎么说话」
- `学说话.md` 留空，**等被纠正了再来写**

## 1.5 验证它还活着

在 DSH 里问一句：

> 你记得我们上次说到哪了吗

它答「不记得」，是对的 —— 记忆是空的。它如果编了一个「上次」，说明
`AGENTS.md` 第 1 节（开口之前先落地）没放进去，或者放错目录了。

---

## 装不上怎么办

| 现象 | 多半是 |
| --- | --- |
| DSH 里没有 `AGENTS.md` 生效 | 放错目录了，要在**当前会话的工作目录**里，不是 DSH 安装目录 |
| 插件 `dsh plugin … add` 报版本冲突 | 插件要求 `dsh >= x.y`，先升 DSH |
| 装完插件 DSH 起不来 | 看 DSH 日志。插件报错会写进日志，不会在界面上弹 |
| 插件装了但工具列表里没有 | 插件只在**新建会话**里生效，旧会话不会热加载 |
