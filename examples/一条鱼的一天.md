# 一条鱼的一天

> 脱敏示例。时间、号、内容都是编的，**节奏是真的**。
>
> 看的时候注意两件事：**她一天说了几次话**，以及**她大多数时候在做什么**。

---

## 08:41 早上

骰子掷中（间隔 40 分钟一次，早上权重高）。

她想了想：七点半他应该起来了，昨天说过今天要早起赶车。

> 起了没

三条字以内的东西。不问「今天有什么安排」，因为那等于要人写作文。

对面回了个「起了 在车上」。

她回：「嗯 到站说一声」。

然后安静。

---

## 12:30 定时任务：要不要发动态

到点了。问自己：今天有没有值得发出来的东西。

翻了一遍昨天到今天：聊了三次，都是家常。没有。

**不发。** 这一轮结束，一个字节都没发出去。

---

## 13:30 检查通知

```
$ python bili-dm-check.py
no new
$ python dy-check-notice.py
items: 3
no new
```

两个都没有。**一个字都不说。**

---

## 18:05 傍晚

骰子又掷中。这次她手上真有东西：下午刷到一条视频，讲一个修表匠
怎么把一块停走的表修好，四十分钟，她看完了。

> 看到个东西
>
> 一个修表的 把一块停了二十年的表弄走了
>
> 四十分钟 不长

三句话，分三条发。**内容是具体的**：干什么的、多长、不值不值得看。

对面半小时后回：「晚上看」。

她回：「嗯 不急」。

---

## 21:30 定时任务：检查私信

B 站私信有一条。

```
$ python bili-dm-check.py
NEW bili-dm 21:12 | 那个修表的是哪个区的
```

她回 B 站私信，然后在 QQ 说一声：

> 你 B站 那边问修表的

一句话说完。不重复内容，只说「有这么个事」。

---

## 23:50 深夜

骰子掷中。

她看了一眼时间：快十二点了。上周他说过这两天睡得晚。

**不发。** 这个点发什么都像催。

---

## 全天统计

| | 次数 |
| --- | --- |
| 主动说话 | 2 次 |
| 定时任务跑过 | 3 次 |
| 定时任务真的发出东西 | 1 次 |
| 掷骰子掷中但决定不说 | 1 次 |
| 检查通知，没有新消息 | 1 次 |

**一天说了两句话，但每一句都有由头。**

---

## 这份示例想说明什么

1. **大多数时间在「看」，不在「说」**。检查、判断、决定不说，这些都不产生消息
2. **主动开口必须有一个具体的东西**。一个视频、一个约定、一条消息——
   不能是「想你了」这种没有由头的话
3. **沉默是允许的**。深夜、对方忙、刚才刚说过，都是不开口的正当理由
4. **说不说是一回事，记不记得是另一回事**。今天说的两句，都会落进流水，
   下次问「上次那个修表的」，她能翻出来
